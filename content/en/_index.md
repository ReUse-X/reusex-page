# Turn existing buildings into circularity-ready data with AI
AI-powered resource mapping from LiDAR — reuse-focused 3D models and inventories for faster transformation decisions.

{{< section id="about" >}}
## Current Challenges
The transformation and reuse of existing buildings is held back by the lack of reliable data.

{{< cards >}}
{{< card icon="warning" >}}
### Manual mapping
Resource mapping is done by hand, building by building – slow, expensive, and inconsistent.
{{< /card >}}

{{< card icon="puzzle" >}}
### Poor data on existing stock
Drawings are outdated, BIM models don’t exist, and point clouds stay locked in specialist tools.
{{< /card >}}

{{< card icon="currency" >}}
### Regulatory pressure
Circularity, reuse, and taxonomy requirements demand better documentation than current methods can deliver.
{{< /card >}}
{{< /cards >}}
{{< /section >}}

{{< section >}}
## The ReUseX Solution
AI-powered resource mapping from LiDAR → circularity-ready 3D models and inventories for faster transformation decisions.

{{< cards >}}
{{< card icon="lightning" >}}
### From scan to 3D model
Convert LiDAR scans into simplified, analysis-ready 3D models of existing buildings.
{{< /card >}}

{{< card icon="network" >}}
### AI-powered resource mapping
Automatically detect structural elements and building components in the point cloud using AI segmentation.
{{< /card >}}

{{< card icon="chart" >}}
### Reuse inventories & exports
Generate component inventories and exports that plug into simple 3D, spreadsheets, and analysis workflows.
{{< /card >}}
{{< /cards >}}
