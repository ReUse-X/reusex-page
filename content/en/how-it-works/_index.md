# How it Works
ReUseX turns raw LiDAR scans of existing buildings into reuse-ready models and data packages.
{{< /hero >}}

{{< section id="on-site-registration" >}}
## Step 1: On-site registration
{{< steps >}}
{{< step title="Scan + 360° images" icon="tablet" >}}Capture LiDAR scans of the building and 360° imagery for visual context. The imagery supports interpretation, review, and traceability during analysis.{{< /step >}}
{{< step title="Initial manual classification" icon="table" >}}A light first-pass classification is added (quick tagging of key areas/components). This improves consistency and gives the AI a structured starting point.{{< /step >}}
{{< step title="Upload of scan data" icon="upload" >}}Scan + imagery are uploaded to the ReUseX workflow (or transferred via an agreed secure method). The dataset is checked for completeness before processing.{{< /step >}}
{{< /steps >}}

**Output from this section:** a verified input dataset ready for computation.
{{< /section >}}

{{< section id="compute" >}}
## Step 2: Compute
{{< steps >}}
{{< step title="Point cloud is generated" icon="cube" >}}ReUseX processes the scan data into a unified point cloud aligned to a consistent coordinate system, ready for segmentation and modelling.{{< /step >}}
{{< step title="AI segmentation + simple 3D model" icon="sparkles" >}}ReUseX applies AI to segment the point cloud into building components and generates a simplified 3D model designed for early-phase decisions (screening, quantities, collaboration).{{< /step >}}
{{< /steps >}}

**Output from this section:** segmented point cloud + simplified 3D model + structured component data
{{< /section >}}

{{< section id="platform" >}}
## Step 3: Platform
{{< steps >}}
{{< step title="Data accessible on the platform" icon="monitor" >}}Users access the 3D model, segmented components, inventories, and documentation in one shared dashboard—so municipalities, owners, and consultants work from the same dataset.{{< /step >}}
{{< step title="Report generated" icon="document" >}}A report package is produced based on the model and inventories, documenting inputs, outputs, and key findings to support transformation and reuse decisions.{{< /step >}}
{{< step title="Collaborative decision-making" icon="share" >}}Stakeholders can share insights, annotate components, and collaborate on reuse strategies—ensuring all parties align on material recovery priorities and next steps.{{< /step >}}
{{< /steps >}}

**Output from this section:** platform access + exports + report package for stakeholders.
{{< /section >}}
