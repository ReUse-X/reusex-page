{{< slide >}}
## The Problem
Decisions are made early — on a weak foundation

{{< steps >}}
{{< step >}}
### Too late
Resource mapping is carried out too late to influence the choice between transformation and demolition.
{{< /step >}}

{{< step >}}
### Too expensive and difficult
Manual surveys require specialist knowledge and are so costly that they are often skipped.
{{< /step >}}

{{< step >}}
### New build wins by default
Without data, demolition and new build appear the "safe" choice.
{{< /step >}}
{{< /steps >}}

The result: the circular economy remains an ambition rather than an operational practice.
{{< /slide >}}

{{< slide >}}
## The Solution
AI-driven resource mapping in three steps

{{< steps >}}
{{< step >}}
### Scan with iPhone / iPad
LiDAR scanning with readily available equipment — no specialist knowledge needed. Supplemented with 360° images for visual context.
{{< /step >}}

{{< step >}}
### AI analyzes
A point cloud is generated. A neural network automatically segments building components: walls, slabs, columns and openings.
{{< /step >}}

{{< step >}}
### Platform and output
A semantic 3D model and a structured material list with metadata — edited, validated and shared in one common dashboard.
{{< /step >}}
{{< /steps >}}

Documented: approx. **1,700 m² in approx. 30 minutes**, surveyed and processed into a decision-ready dataset.
{{< /slide >}}

{{< slide >}}
## Step 1 — Scanning
iPhone / iPad with LiDAR in the field

- Standard equipment — iPhone or iPad Pro with a LiDAR sensor
- No special skills required of the person scanning
- 360° images supplement the point cloud with visual context
- App-based workflow — easy to integrate into existing processes
- Approx. 30 minutes for 1,700 m² — the barrier to entry is broken down
{{< /slide >}}

{{< slide >}}
## Step 2 — AI analysis
From raw point cloud to structured data

- A neural network automatically segments all building components
- Walls, slabs, columns and openings are classified with no manual post-processing
- Colour-coded output shows the type and position of each element
- From raw scan to structured dataset in minutes
{{< /slide >}}

{{< slide >}}
## Step 3 — Platform
An interactive 3D dashboard and material list

- Semantic 3D model with full metadata per building component
- Structured material list ready for LCA and carbon accounting
- Shared dashboard for building owners, consultants and municipalities
- Export to standard formats and API integration
{{< /slide >}}

## Sustainability
Reuse starts with data

- **Circular economy** — maps 1,700 m² in 30 minutes, before the demolition decision is locked in and while reuse is still an option
- **CO₂ reduction** — every tonne reused instead of newly produced saves embodied carbon; compare scenarios from day one
- **Regulation-ready** — the documentation supports BEK 496/2024 on selective demolition and the EU taxonomy
- **Less waste** — better data before demolition enables more targeted sorting and more reuse instead of landfill
- **Extended lifespan** — a mapping lives on as a material passport for future LCA calculations and projects

## The Journey
From research to recognition

{{< steps >}}
{{< step marker="2021–22" >}}
### Industrial PhD
The research foundation for ReUseX, at LINK Arkitektur.
{{< /step >}}

{{< step marker="2022–24" >}}
### Technological foundation
A computer-vision pipeline for mobile 3D scanning, developed with the Alexandra Institute; AI segmentation of building components tested and validated.

{{< step marker="2024" >}}
### Validation and recognition
First pilot projects with municipalities and private stakeholders. PhD defence: "3D Mapping of Vacant Buildings for Reuse". Nominated for — and runner-up of — Industriens Fond's AI Prize.
