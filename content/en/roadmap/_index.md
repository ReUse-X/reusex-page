## 2026 — From scanning to repeatable delivery

In 2026, ReUseX moves from prototype to repeatable delivery by turning scanning data into structured, decision-ready reuse datasets and strengthening the full workflow around it. We build and harden the end-to-end pipeline (capture → segmentation → inventory), add reliable metadata and validation flows with confidence scoring, and run multiple pilots to improve AI performance and reduce manual cleanup. By the end of the year, the focus shifts to productization: multi-stakeholder project workflows, export/API integrations, and standardized reporting outputs—so ReUseX can be deployed consistently across projects without compromising quality.
{{< /section >}}

{{< section id="roadmap-26" >}}
## Roadmap '26

{{< steps >}}
{{< step title="Needs, standards, and compliance" marker="2026 Q1" >}}
User needs analysis with resource mappers/coordinators (workflows, pain points, “must-have” features). Define data requirements for documentation, traceability, and selective demolition reporting. Establish a shared classification structure for components/materials (foundation for interoperability)
{{< /step >}}
{{< step title="Pilots and model improvement" marker="2026 Q2" >}}
Run multiple pilots across building types; collect feedback + validation data. Improve recognition/segmentation quality (model tuning + edge-case handling). Confidence scoring + “review required” flags to guide validation efficiently. Reduce manual cleanup time with smarter post-processing and batch edits
{{< /step >}}
{{< step title="Productization and integrations" marker="2026 Q3" >}}
Harden platform workflows for multi-stakeholder reuse projects (roles, permissions, review steps). Integration layer: APIs + connectors for downstream tools and partner systems. Reporting templates (resource overview, reuse potential, documentation package). Pricing and packaging: repeatable delivery model (service + platform) and partner rollout kit
{{< /step >}}
{{< step title="ReUseX v1 launch readiness" marker="2026 Q4" >}}
Self-serve onboarding + project setup templates (faster “time to first result”). Robust project management: versions, audit trail, and dataset comparability across iterations. Expanded component/material library and improved classification coverage. Performance upgrades for larger scans and more complex datasets
{{< /step >}}
{{< /steps >}}

{{< section id="2027" >}}
## 2027 — Launch and scale adoption

In 2027, ReUseX shifts from repeatable delivery to scaled adoption. We finalize a v1-ready product with faster onboarding, stronger project/version management, and broader component/material coverage, then expand production-grade integrations through APIs and connectors to fit into partner ecosystems. As usage grows, we operationalize quality and support with training playbooks, automated checks, and portfolio-level insights, while maturing enterprise features and localization to prepare for expansion into new markets.
{{< /section >}}
